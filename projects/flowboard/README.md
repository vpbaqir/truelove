# Flowboard — Personal Kanban

A small local-first Kanban board for moving tasks through To do, In progress, and Done.

## Run
Open `index.html` in a modern browser. No dependencies, server, or account required.

## Features
- Add tasks with notes and priority.
- Move tasks across three columns or delete them.
- Search titles and notes.
- Export the board as JSON.
- Responsive layout, keyboard-accessible controls, and empty states.

## Privacy
Tasks are stored in this browser's localStorage. They are not synced to a server. Anyone using the same browser profile may be able to see them.

## Limitations
No collaboration, cloud sync, due dates, or account system. Clearing browser data can remove saved tasks; export a backup regularly.
