# Timetable Forge

A mobile-friendly weekly timetable builder.

## Run
Open `index.html` in a modern browser. No build tools or network required.

## Features
- Add and remove activities by weekday and time
- Chronological daily columns
- Export a JSON backup

## Privacy
Data stays in the current page session and is not uploaded. Export to keep a copy.

## Limitations
No account, sync, recurring-event rules, or conflict detection.
