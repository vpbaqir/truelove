# Arabic Wordloom

A local Arabic vocabulary deck for beginner practice.

## Run locally
Open `index.html` in a modern browser. No build step is needed.

## Features
- Reveal meanings, navigate cards, mark words known or to revisit.
- Add custom words and export a JSON backup.
- Arabic right-to-left display and responsive controls.

## Privacy
Words and progress are stored in this browser only. No server or network calls.

## Limitations
Starter meanings are simplified study glosses, not a full dictionary. No audio, pronunciation scoring, or cloud sync.
