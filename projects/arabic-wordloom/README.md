# Arabic Wordloom

Open `index.html` in a modern browser. No build tools are needed.

## Features
Reveal word meanings, navigate the deck, mark words known or to revisit, add custom words, and save progress locally.

## Privacy
The app uses this browser's local storage and makes no network requests.

## Limitations
Starter meanings are simplified study glosses. There is no audio, pronunciation scoring, export, or cloud sync.
