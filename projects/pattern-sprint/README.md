# Pattern Sprint — Memory Game

A compact memory game where each round adds one tile to a sequence. Watch, repeat, and try to beat your personal best.

## Run it
Open `index.html` in a modern browser. No install, account, sound or network connection is needed.

## Features
- Nine-tile sequence game with increasingly long rounds.
- Timed visual cues and immediate feedback.
- Keyboard-accessible native buttons with labels.
- Personal best saved locally.
- Responsive dark interface and restart/reset controls.

## Privacy
Only the best score is saved in browser `localStorage`. No telemetry or remote requests are included.

## Limitations
- The game is single-player and has no leaderboard or cloud sync.
- A round ends when a tile is tapped out of sequence.
- Clearing browser storage resets the personal best.
