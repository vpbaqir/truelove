# Orbit Logic — Lights Puzzle

A logic game where each move toggles a tile and its orthogonal neighbours. Solve the board by turning every light off.

## Run
Open `index.html` in a modern browser.

## Features
- Five-by-five tile puzzle.
- Solvable boards generated by applying random moves to a cleared board.
- Move counter, undo, reset, and new puzzle.
- Personal best saved locally.
- Keyboard-accessible buttons and responsive layout.

## Privacy
Only the personal-best move count is stored in browser `localStorage`. No gameplay data is uploaded.

## Limitations
There is no hint solver, leaderboard, or multi-level campaign. New boards vary in difficulty.
