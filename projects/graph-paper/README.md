# Graph Paper

An accessible, local graphing canvas for exploring linear and quadratic equations with adjustable coefficients.

## Run
Open `projects/graph-paper/index.html` in a modern browser. No build step or backend is required.

## Features
- Plot y = mx + b or y = ax² + bx + c
- Adjust coefficients with sliders and numeric inputs
- Responsive canvas with grid, axes, and origin
- Read the current equation and sample value

## Privacy
All calculations and drawing happen locally in the browser.

## Limitations
This learning tool plots only linear and quadratic functions; it is not a symbolic algebra system.
