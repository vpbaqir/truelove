# Contrast Studio — Color Accessibility Checker

A browser-based utility for checking text/background color contrast and previewing readable color combinations.

## Run it
Open `index.html` in a modern browser. No dependencies or network access are needed.

## Features
- Choose foreground and background colors with color pickers or hex fields.
- Live preview of sample text.
- Contrast ratio calculation and WCAG AA/AAA normal-text indicators.
- Swap and reset controls, responsive layout and validation for hex input.

## Privacy
Color values and preview text are processed locally and are not stored or sent anywhere.

## Limitations
This checks a single color pair only. It does not assess font weight, layout, focus states, images, or the full accessibility of a website. Verify your interface in context.
