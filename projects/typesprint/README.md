# TypeSprint — Typing Practice

A self-contained 60-second typing challenge with live speed and accuracy feedback.

## Run
Open `index.html` in a modern browser. No dependencies or internet connection are required.

## Features
- Four practice passages across different topics.
- Timer starts on first keystroke.
- Live WPM and character accuracy.
- Character-level correct / incorrect feedback.
- Personal best saved locally, restart, and passage switching.
- Responsive, keyboard-first typing area.

## Privacy
Typing input is processed in the page. Only personal-best WPM is saved in browser `localStorage`. No keystrokes are uploaded.

## Limitations
WPM is estimated from correct characters divided by five and elapsed time; it is a practice metric, not a formal assessment. No accounts or leaderboard.
