# Qalam — Arabic Vocabulary Studio

A polished, mobile-first Arabic vocabulary trainer designed for daily practice. It works entirely in the browser, with no account, API key, or build step.

## Learning features
- Curated starter deck with Arabic words, transliteration, English meaning, and example phrases
- Flashcards with reveal, known / practice actions, and keyboard support
- Short multiple-choice review quiz
- Simple spaced-review scheduling: known cards return later; difficult cards return sooner
- Search and filter vocabulary by learning status
- Daily goal, streak, and progress summary
- Add your own words and meanings
- Local persistence with localStorage
- RTL Arabic typography and responsive layout

## Run
Open `index.html` in a modern browser. No dependencies are required.

## Privacy and limitations
All data remains in this browser on this device. This is an educational MVP, not a cloud-synced product. Starter vocabulary is intentionally small; review Arabic examples with a qualified teacher before using them for formal study.
