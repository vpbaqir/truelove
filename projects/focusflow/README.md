# FocusFlow — Student Focus Planner

A lightweight, mobile-first study planner built as a standalone HTML/CSS/JavaScript app. No framework, build step, account, or API key required.

## Features
- Add and complete study tasks
- Pick a subject and estimate study time
- Built-in focus timer with start, pause, and reset
- Daily progress and completion statistics
- Saves tasks locally in the browser with localStorage
- Responsive layout for phones and desktops
- Keyboard-friendly controls and reduced-motion support

## Run
Open `index.html` in a browser. For the best experience, serve this folder with any static web server.

## Privacy
Tasks stay in the browser on the current device. There is no backend and no analytics.

## Project status
MVP prototype. Data is local to the browser and does not sync across devices.
