# HifzPath — Revision Planner

A local planner for naming memorisation portions and scheduling review dates.

## Run
Open `index.html` in a modern browser.

## Features
- Add portions with notes and first review dates.
- See how many entries are due and how many are saved.
- Review buttons schedule the next date.
- Export a JSON backup or clear the plan.
- Responsive layout and local storage.

## Privacy
Entries stay in this browser's `localStorage`; they are not uploaded. Export a backup before clearing browser data.

## Limitations
Review intervals are a simple reminder aid, not a validated learning method. No accounts, notifications, or sync.
