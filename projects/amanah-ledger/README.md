# Amanah — Pocket Ledger

A private, mobile-first money tracker for recording income and expenses without creating an account.

## Run it
1. Open `index.html` in a modern browser, or serve this folder with any static web server.
2. Add a transaction with its amount, category and date.
3. Use the month and activity filters to review records.
4. Choose **Export CSV** to keep a copy outside the browser.

## Features
- Monthly balance, income and expense totals in INR.
- Add and delete dated transactions.
- Filter by month and transaction type.
- CSV export for backups or spreadsheets.
- Responsive layout, keyboard-friendly controls and clear empty states.

## Privacy
Records are stored in this browser's `localStorage`. They are not sent to a server. Anyone using the same browser profile may be able to see them. Export regularly; clearing browser storage can erase the ledger.

## Limitations
No account, cloud sync, bank connection, recurring transactions or financial advice. Currency is fixed to INR.
