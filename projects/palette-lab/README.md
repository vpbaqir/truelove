# Palette Lab — Color Palette Maker

Generate a five-color palette from a base color, preserve favorite swatches, and export CSS custom properties.

## Run
Open `index.html` in a modern browser. No dependencies or network connection are needed.

## Features
- Base color picker and hex validation.
- Hue-based palette generation and random starting colors.
- Lock individual swatches while regenerating.
- Copy hex values and export CSS variables.
- Live sample interface and responsive layout.

## Privacy
Colors are processed in memory only. The app does not upload or persist palettes.

## Limitations
Generated harmonies are a starting point, not a guarantee of accessible contrast. Check text and interaction states in your actual design.
