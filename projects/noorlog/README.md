# NoorLog — Daily Intentions

A calm daily habit tracker with optional reflection notes.

## Run it
Open `index.html` in a modern browser. No build tools or network connection are required.

## Features
- Add and remove personal intentions.
- Mark intentions complete for a selected day.
- Review completion for the previous seven days.
- Write a daily reflection that saves automatically.
- Mobile-first responsive UI and accessible form controls.

## Privacy
Habits, checkmarks and notes are saved in this browser's `localStorage`; they are not uploaded. Avoid storing sensitive details on a shared device.

## Limitations
No account, cross-device sync, notifications or cloud backup. Clearing browser storage may erase data.
