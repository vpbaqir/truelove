# Interval Studio — Custom Timer

A focus-and-rest interval timer with presets and adjustable rounds.

## Run
Open `index.html` in a modern browser. No dependencies or network connection are required.

## Features
- Pomodoro and short-sprint presets.
- Configurable focus/rest durations and round count.
- Round counter, progress bar, pause/resume, and reset.
- Responsive interface and session-complete state.

## Privacy
The app does not collect or store personal data.

## Limitations
Browser timers may be throttled when the tab is backgrounded or the device sleeps. Use a dedicated timer for critical timing.
