# Zakat Compass — Personal Estimate

A transparent calculator for exploring a simplified zakat estimate using values supplied by the user.

## Run
Open `index.html` in a modern browser. No server or API key is required.

## Features
- Enter asset categories, deductible liabilities, and a chosen nisab threshold.
- See total assets, net amount, eligibility comparison, and a 2.5% estimate.
- INR formatting and responsive form controls.
- No automatic persistence; reset clears the inputs.

## Privacy
All calculations happen in the browser tab. Values are not uploaded or saved by the app.

## Religious and calculation limitations
This is an educational arithmetic aid, not a fatwa or a complete fiqh calculator. It assumes entered assets are eligible and does not independently determine ownership rules, nisab values, lunar-year conditions, asset-specific treatment, or deductible liabilities. Use current guidance from a trusted source and consult a qualified scholar for your situation.
