# Passphrase Studio

Generate a memorable phrase locally in the browser.

## Run
Open `index.html` in a modern browser with Web Crypto support.

## Features
- Configurable word count
- Optional number and symbol
- Copy to clipboard where browser permissions allow

## Privacy
The phrase is generated locally and is not uploaded or saved.

## Limitations
The demo uses a small illustrative word list and is not a formally audited password manager. Avoid reusing generated phrases across accounts.
