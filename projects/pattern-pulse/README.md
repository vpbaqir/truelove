# Pattern Pulse

A touch-friendly sequence-memory game. Watch the lights, repeat the sequence, and try to beat your best round.

## Run locally

Open \`index.html\` in a modern browser or serve this folder as static files. No dependencies or network connection are needed.

## Features

- Nine-button sequence board with increasing difficulty.
- Clear playback/input states, round counter, sequence length, and local best score.
- Replay the current pattern and restart at any time.
- Native buttons support keyboard activation; visible focus styles and reduced-motion handling are included.

## Privacy

The game does not collect or transmit data. Only the best score is stored in browser local storage.

## Limitations

- Single-player only; no leaderboard, account, sound, or multiplayer.
- Random sequences are generated in the browser and are not intended for scientific cognitive assessment.
