# Recipe Scale — Kitchen Helper

A simple ingredient calculator that adjusts amounts for a different number of servings.

## Run it
Open `index.html` in a modern browser. No dependencies or network connection are required.

## Features
- Change original and target serving counts.
- Add ingredients with quantities and units.
- Live scale factor and scaled amounts.
- Tick ingredients as you prepare them, load a sample list, or clear the list.
- Export the scaled list as a text file.
- Responsive layout with accessible form controls.

## Privacy
The ingredient list is saved in browser `localStorage`. It is not sent to a server. Exported lists are downloaded to your device.

## Limitations
This scales quantities mathematically; it does not adjust cooking time, pan size, seasoning balance or food safety guidance. Some ingredients do not scale linearly in real cooking.
